# Tomato Flutter

Учебная вёрстка пяти экранов на Flutter: регистрация, вход, главная страница, настройки и статистика.

## Возможности

- Register открывает страницу входа, Login — главную страницу.
- Шестерёнка открывает настройки, Report — статистику.
- Стрелка назад возвращает на предыдущую страницу.
- Поля принимают текст; настройки таймера — только цифры.
- Регистрация и вход демонстрационные: данные не проверяются и не сохраняются.
- Кнопки Start focusing и Save отключены. Статистика содержит примерные данные.

## Запуск на Windows

Нужны актуальный Flutter SDK и Visual Studio с рабочей нагрузкой «Разработка классических приложений на C++», включая MSVC, CMake и Windows SDK.

```sh
flutter pub get
flutter run -d windows
```

В VS Code можно выбрать конфигурацию Flutter Windows и нажать F5.

## Структура

- lib/main.dart — страницы и простые переходы.
- lib/previews.dart — предпросмотр страниц через Flutter Widget Preview в VS Code.
- assets/ — исходные SVG-картинки.
- windows/ — файлы Windows-приложения.

Папки остальных платформ не содержат готовых проектов. При необходимости их можно сгенерировать через flutter create с нужной платформой. Git не сохраняет пустые папки.

## Проверка

```sh
flutter analyze
flutter test
```

Проект использует flutter_svg для отображения SVG. Код предназначен для изучения Flutter, без сервера, авторизации и работающего таймера.
